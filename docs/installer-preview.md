# インストール前の確認

インストーラは、選択したモジュールに必要なパッケージ、更新候補、配置する設定ファイル、容量の目安を確認画面に表示します。`INSTALL`と入力するまでインストールは始まりません。

```bash
bash setup_all.sh --modules neovim,ros2 --dry-run
bash setup_all.sh --modules shell,git-tools,atuin --dry-run --show-diff
```

`--dry-run`はファイル変更、通信、`sudo`、APTの情報更新を行いません。ユーザーの設定ファイルやプロジェクトのスクリプトも実行しません。

設定ファイルは通常、パスと`NEW`、`UPDATE`、`CURRENT`などの状態だけを表示します。`--show-diff`を追加するとテキストの差分も表示します。各ファイルの差分は80行までで、大きなファイル、ディレクトリ、ホーム外へのリンク先の内容は表示しません。パスワードやメールアドレスなどを含むと判断した行は伏せますが、任意の設定の秘密情報を完全には判別できません。出力を他の人へ渡す前に内容を確認してください。

WSLで`fonts`を選択した場合は、システム設定の`/etc/wsl.conf`も確認対象です。`[interop]`の`enabled`と`appendWindowsPath`を`true`にする変更予定を表示し、`--show-diff`では同じ行数制限と伏せ字処理を使って差分を表示します。確認中は書き込みも`sudo`も行いません。インストール開始後、変更が必要な場合だけ元のファイルを`/etc`内へバックアップして更新します。ほかの設定やコメント、所有者、アクセス権は維持します。

Windows連携の設定変更後はUbuntu側のインストールを続け、Windows側のフォント登録は保留します。最後にWSLの再起動とフォント設定の再開コマンドを表示します。再起動やログイン時のコマンド実行を自動登録することはありません。手順は[外観と端末の設定](appearance.md#nerd-fontとアイコン)を参照してください。

既にリポジトリへリンクされている設定は、`git pull`した時点で内容が切り替わります。この場合の`CURRENT`は「リンク先が正しい」という意味です。Git更新前の内容との差分は`git diff HEAD@{1} HEAD -- configs/`などで確認してください。

APTの候補バージョンと容量は、この端末にあるキャッシュを使って計算します。シミュレーションで必要と判定された依存パッケージも含みます。ダウンロード量はAPTのアーカイブキャッシュを再利用する前の値で、インストール後の容量は既存パッケージとの差分です。キャッシュが古い場合や、ROS・Chromeなどの配布元がまだ登録されていない場合は、実行時の結果と異なります。他のUbuntuリリース・CPU向けにプレビューした場合、端末のAPT情報を流用せず`UNKNOWN`と表示します。

ユーザー用ツールは、管理対象ディレクトリの記録やnpmの`package.json`から確認します。プレビューのためにインストール済み実行ファイルを起動することはありません。`CACHED`は対応するダウンロード済みツールの記録があるという意味で、実際の配置・検証はインストール時に行います。

容量の一部が不明な場合は、既知の小計と`UNKNOWN`を分けて表示します。npm・uvの依存解決、Rustのコンポーネント、プラグイン、ビルドの一時ファイル、旧バージョンの保持、設定のバックアップなども容量を使います。システム・ホーム・一時ディレクトリの空き容量を確認し、小計だけで容量が十分と判断しないでください。

GNOME、IME、Windows Terminal、フォント登録、アプリのランチャーなど、セッションや導入後の状態に依存する設定は、このオフライン画面で完全な差分を表示しません。変更対象の機能を表示し、実行時に既存のバックアップ機能で元の設定を保存します。
